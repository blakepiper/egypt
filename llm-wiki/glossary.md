# Glossary

| Term | Concise definition |
|---|---|
| **akh** | effective, transfigured spirit capable of action among gods and dead |
| **akhet** | horizon or threshold of solar appearance/transformation |
| **Amduat** | “What is in the Duat,” a royal New Kingdom guide to Re's twelve-hour night journey |
| **amulet** | material form worn or placed for a specific protective or transformative power |
| **ankh** | hieroglyph and object signifying life |
| **apotropaic** | able to avert or repel harm |
| **ba** | mobile manifestation of a person, often a human-headed bird |
| **barque/bark** | sacred boat used by a deity in cosmic travel or festival procession |
| **canopic jars** | vessels associated with preserved viscera and the four Sons of Horus |
| **charter myth** | origin account that validates an institution or order |
| **cippus** | healing/protective stela, commonly Horus the Child mastering dangerous animals |
| **counterimage** | representation functioning as an effective substitute or presence |
| **Duat** | hidden realm of solar night journey, gods, and dead; not simply “hell” |
| **Ennead** | a grouping of nine deities, especially the Heliopolitan family from Atum |
| **etiological myth** | story explaining an origin, feature, or custom |
| **heka** | effective magical power and its divine personification |
| **hem-netjer** | “god's servant,” a high priestly title |
| **historiola** | short mythic precedent embedded in a spell |
| **ib/ab** | heart as seat of mind, memory, character, and testimony |
| **isfet** | disorder, falsehood, violence, and breakdown opposed to maat |
| **ka** | vital potency/continuing recipient or double sustained through offerings |
| **khaibit/shut** | shadow, a vulnerable extension or aspect of presence |
| **khery-heb / lector priest** | ritual specialist identified by sash and scroll, responsible for recitation |
| **Maat** | truth, justice, proper cosmic-social order; also its goddess |
| **natron** | naturally occurring salts used in purification and desiccation |
| **negative confession** | Chapter 125 declarations of wrongs the deceased says they did not commit |
| **nome** | modern term for an Egyptian administrative district with local cult traditions |
| **Nun** | primeval undifferentiated water before and around creation |
| **Ogdoad** | group of eight primeval deities, especially at Hermopolis |
| **Opening of the Mouth** | ritual enabling an image or mummy to breathe, eat, see, hear, and receive offerings |
| **operative myth** | story whose ritual recitation is intended to effect reality |
| **phyle** | rotating service group of priests or workers |
| **pylon** | monumental twin-towered gateway of a temple |
| **rekhet** | woman serving as a medium or spirit specialist in the reference material |
| **ren** | name as a constitutive element of identity |
| **Rosetau/Rosetjau** | Memphite necropolis/transition region generalized into otherworld geography |
| **rubric** | instruction or heading distinguished in red ink in funerary manuscripts |
| **Sed festival** | royal jubilee renewing fitness, potency, and rule |
| **sem priest** | ritual priest wearing a leopard skin, prominent in funerary rites |
| **shabti** | funerary figure intended to answer labor summons for the deceased |
| **sistrum** | shaken musical instrument associated especially with Hathor and temple women |
| **tekenu** | enigmatic wrapped funerary bundle or figure in processions |
| **vignette** | image accompanying and activating/clarifying a funerary spell |
| **wab** | “pure” priest, often serving in temple rotation |
| **wabet** | “pure place,” embalming workshop or purification setting |
| **was scepter** | emblem of divine power/dominion |
